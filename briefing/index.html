Legal basis, in detail

Foreign compulsion. The US CLOUD Act reaches data within a provider's “possession, custody, or control” (18 U.S.C. §2713).

The Government of Canada's white paper on data sovereignty and public cloud names the primary risk: “the US Foreign Intelligence Surveillance Act (FISA) and the US government's ability to compel an organization subject to US law to turn over data under its control, regardless of the data's location and without notifying Canada.”

BC privacy law. FIPPA s.33.1 allows disclosure outside Canada only as the regulation permits.

B.C. Reg. 294/2021 s.2 applies the supplementary assessment to sensitive personal information stored outside Canada.

A Deep Cove installation stores and processes all patient information on site, so the assessment is not triggered.

Scoring method, in detail

System and settings. Kit Think, one attempt per item per run (PhysicianBench and SDBench: two full runs, both scored), on Deep Cove Intelligence's current hosted service with live web search on, the same kind of search the Web Librarian provides on a Deep Cove installation.

Every installation re-runs the published boards on site at acceptance, against pass marks BC sets.

Run dates: 14–15 November 2026 (UTC).

Grading. Ten boards on their own published grader, unmodified.

Three multiple-choice boards by exact answer match, with the script in the pack.

Three that publish no scoring code by a named judge model, with its prompt in the pack.

As delivered. We scored every item as delivered.

We edited, re-ran or removed no answer after grading.

The one exception is two chest X-ray reports the judge's parser could not read, excluded from that board's mean and kept in its pack.

Each pack's score recomputes from its own results file.

The index lists every zip with its SHA-256 sum.

Small public sets. Vals Finance Agent and BrokenArXiv are complete public sets of 27 and 53 items.

How a gate works, in detail

Power and the other lines. The Core runs on hospital power, with battery backup and the generator behind it.

A site that chooses the Sealed Library has no outbound line.

Its library comes in through the Delivery Bay.

A one-way monitoring link carries security events, never patient text, to the hospital's security operations.

The orders. The Core can send four kinds of order: a web search, a page read, a library lookup and a record lookup.

It can never send a free web address or a database query.

Its search words are short, checked twice and rebuilt from approved terms.

A page read can name only a result the Web Librarian itself returned.

The Gates. Each gate is a pair of one-way links that end in single-purpose checking proxies on separate hardware.

No network session crosses a gate.

The gate checks each message against a fixed schema and against business rules.

It drops a failing message whole and logs every message.

Record lookups run with the signed-in clinician's own access rights, never through a broad service account.

The librarian rebuilds returned text as plain text before it reaches the Core.

No web page, script or macro arrives as it was fetched.

Mapped to recognized standards. The design maps to NIST SP 800-53 (AC-4 information-flow enforcement) and SP 800-207, the Canadian Centre for Cyber Security's network-zone model (ITSP.80.022) and the UK NCSC “Safely Importing Data” pattern.

It is mapped to these standards, not certified against them.

Questions officials ask.

Where does patient data go, and who can see it?

It stays in the facility.

Kit reads a record only through the Records Librarian, and only what the signed-in clinician may already see.

The only things that leave are a few search words, cleaned by the Web Librarian, with no patient identifiers, and requests for the public pages they return.

A site on the Sealed Library has no outbound line.

For rural sites served by a regional installation, questions travel only on the provincial health network between BC health-authority facilities.

Deep Cove Intelligence has no remote access and holds no copy.

Is patient data used to train the AI?

No. A Deep Cove installation has no training system.

The model files are read-only and checked against their fingerprint at every start.

The agreement forbids any use of BC data for training, tuning or product improvement, and that clause survives the end of the contract.

Which AI model runs inside?

Deep Cove does not trust the model.

The model runs on the Core with no network, no credentials and no write path.

The only thing it can do is place schema-checked orders through the Gates, and separate machines decide whether to act on them.

The buyer receives the model's identity and its evaluations under NDA in due diligence.

How fast is it?

On Kit's current hosted service, measured with test questions (no BC patient data), Kit Ask streams its first words in about 1.5 seconds (median of 690 measurements).

Kit Think shows its first progress line within about half a second and finishes a hard medical question in about one to two minutes.

On a Deep Cove installation, Kit Ask is specified at 1 second or less to first words (95th percentile) at the guaranteed capacity.

Answers stream in the range of the fastest cloud AI services, and Kit Think completion time is contracted for each size.

How is it updated?

Only through the Delivery Bay.

Each update arrives signed.

BC then checks and safety-tests it on a separate machine it owns.

BC's security officer and clinical safety officer sign it off, and two people install it in person.

The previous version stays installed, so rollback is one step.

What if Deep Cove Intelligence is no longer there?

Kit keeps working.

The installation needs nothing from Deep Cove Intelligence to answer questions: there is no licence server, no call-home and no remote off switch.

The agreement sets the continuity terms, including a perpetual licence to the installed version and source-code escrow.

What is Kit not for?

Kit does not make the diagnosis or prescribe.

It lays out the differential, red flags and next steps with their sources, and the clinician decides.

It is decision-support software for licensed professionals.

Image and document reading is non-diagnostic.

Diagnostic imaging will follow the Health Canada medical-device pathway before it is offered.

In an emergency, Kit's first line tells the person to call 9-1-1.
