Expert DetailHow We Measured
  • Runs. Kit Think answered every item on 14–15 November 2026 (UTC), one attempt per item. PhysicianBench and SDBench were run twice in full, and both runs count.
  • As delivered. Every answer was scored as delivered: none was edited, re-run or removed after grading.
  • Grading. Ten boards were scored by their own published grader, unmodified. Three multiple-choice boards were scored by exact answer match. Three publish no grading code, so their packs name the judge model and include its prompt.
  • Web search. On for every board that allows it, on Kit's current hosted service.
  • Images. The two MAST image boards measure reading of public research images. As delivered, Kit does not interpret medical images.
  • Time limits. Board runs gave Kit Think up to 1,170 seconds per item. Kit's current hosted service gives a Kit Think answer up to 300 seconds.
  • On site. The installed configuration is re-scored at acceptance. The boards were not run in the Sealed Library configuration.

Expert DetailInside a Pack, and How to Recompute a Score

What each pack holds

  • README.md: the settings, the grader and the formula.
  • results.jsonl: one row per item: Kit's answer and its grade.
  • actions.jsonl: on the agent boards, every request Kit sent.
  • grader/: scripts and judge prompts, where the board needs them.
  • SHA256SUMS: a checksum for every file.

audit/INDEX.json lists every pack; audit/SHA256SUMS covers every zip.
