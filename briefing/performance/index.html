Sixteen public benchmarks. Every answer open to audit.

Kit Think ran 16 public benchmarks on 14–15 November 2026, one attempt per item in each run. PhysicianBench and SDBench were run twice in full, and both runs count. Kit posts the highest score in the table on clinical safety (NOHARM, 80.0) and on health-record tasks (MedAgentBench v2, 82.0). We publish every answer.

A health system needs more: many boards, the newest rival models beside every score, each board's own grader, and every graded answer open to inspection.

We ran Kit Think on 12 medical and 4 general benchmarks on 14–15 November 2026.

How we measured.

Every Kit number on this page comes from runs graded by the board's rules. Kit Think answered every item on 14–15 November 2026 (UTC): once on fourteen boards, and twice in full on PhysicianBench and SDBench, where both runs count.

We scored every answer as delivered: we edited, re-ran or removed no answer after grading.

One exception: two chest X-ray reports the judge's parser could not read are excluded from the 67.8 mean.

Scoring them at the minimum gives 67.6, and both are in the pack.

Their own published grader, unmodified, scored ten boards. On MAST Chest X-Ray the formula in the pack converts the CRIMSON score to 0–100.

Exact letter or answer match scored three multiple-choice boards, MedQA, GPQA Diamond and LegalBench, with the script in the pack.

Three publish no grading code, so their packs name the judge model and include its prompt or rubric: MedCaseReasoning, BrokenArXiv and Vals Finance Agent.

Each rival number is either published or run by us, and the detail below says which. Published figures come from the board's own leaderboard, the model maker or an independent evaluator.

On PhysicianBench, SDBench and MedCaseReasoning, we ran the rival models ourselves on the same items Kit answered.

Common to all 16 boards

  • System. Kit Think in its evaluated configuration, run with each board's instructions, tools and time limits (up to 1,170 seconds per item; see “Time limits and configuration” below).

    Medical boards ran on the medical path; image boards used Kit's image reading.

    The installed configuration is re-scored on site at acceptance.

  • Attempts. One per item on fourteen boards.

    PhysicianBench and SDBench were each run twice in full, and both runs count (200 scored runs each).

  • Web search. On for every board that allows it, through Kit's controlled search path on its current hosted service, with personal details removed from every search.

    On a Deep Cove installation the same lookups go through the Web Librarian, and the on-site score re-run at acceptance measures that configuration.

    The health-record boards ran against each benchmark's own test record server through the standard FHIR interface.

    No board used a real patient record.

  • Physicians. A physician score appears only where the board's authors measured physicians and published the conditions: NOHARM and HealthBench Professional.

  • Sets under 100 items. BrokenArXiv (53 problems) and Vals Finance Agent (27 tasks) are complete public sets, labelled as such by their count line.

    One BrokenArXiv problem is worth up to 1.9 points; one Vals task up to 3.7.

A router in code picks the path before a model writes a word.

A router written in code picks the path before a model writes a word. Anything about health, medicines, doses or emergencies goes to Kit Think Medical.

When the rules are unsure, the answer is medical.

Deep Cove Research runs when someone asks for a full, cited report.

No mode reaches a source on its own. In Deep Cove, every lookup is a fixed-form order through the Gates to a librarian: the Web Librarian for public sources, the Records Librarian for the clinician's own permitted records.

The modes differ only in how many orders they place.

Check any score yourself.

Every score on this page ships with Kit's answers, the grades and the recipe to recompute it. Each pack is a zip of plain files.

It holds no benchmark question text and no patient-record content, and we edited nothing in it after grading.

What each pack holds

  • README.md, the benchmark and its release, the system and run dates, the settings, the grader, the score and the formula that recomputes it.
  • results.jsonl and results.csv, one row per item: the official item id, Kit's delivered answer and its grade, plus board-specific fields.

  • actions.jsonl, on the agent boards: every request or test Kit sent, in order.

    Server replies and patient-chart text are left out.

  • grader/, where the board needs it: the letter-match script, the judge prompt, the case edits.
  • SHA256SUMS, a checksum for every file in the pack.
sha256sum -c SHA256SUMS
