Capacity is measured on site before go-live.

We measure each installation on site before go-live. The guaranteed figure is the contract number.

The measured figure sits beside it, so BC can see the margin.

On delivery, we replay recorded Kit Ask and Kit Think sessions on BC's installed hardware at the contracted number of simultaneous streams. It passes only when 9 in 10 users stream at 100 tokens per second or more, first words arrive within the contracted time, and no answer fails.

Speed at the guaranteed load

  • Kit Ask: first words in 1 second or less for 95% of questions.
  • Streaming: 100 tokens per second or more for 9 in 10 users, in the range of the fastest cloud AI services and about 19 times human reading speed.

  • Kit Think: its first progress line within 1 second.

    Completion time for a hard medical question written into the acceptance schedule for each size.

How capacity is measured

  • Source: 220 independent measurements of this model in its released format, on each GPU type, dated 5–13 November 2026.

    The measurement source is provided under NDA.

  • Measured figure: the highest number of simultaneous sessions at which 9 in 10 users stream at 100 tokens per second or more.

  • Guaranteed figure: the highest number at which 9 in 10 users stream at 141 tokens per second or more on the same traces.

    The measurements used speculative decoding with a draft acceptance of 3.25–3.51 tokens per step.

    The guaranteed basis still delivers 100 tokens per second at an acceptance of 2.5 (100 × 3.51 ÷ 2.5 = 140.4).

    The on-site acceptance test replaces this margin with the measured figure for Kit's own text.

  • Per 8-GPU server, guaranteed / measured: H200 16 / 32 (64 at peak), B200 384 / 576, H100 8 / 24, B300 544 / 544.

    At Hospital, one entry-class server serves 16 streams and carries on alone if the growth-class server fails.

    The other is the safety-test server and image-reading host.

  • Province: 10,888 simultaneous sessions at 204 tokens per second, measured at peak on 64 GPUs of one rack-scale system.

    × 16 = about 174,000 clinician-equivalents, more than every BC physician and regulated nurse at once.

    This is a peak figure on a different basis from the other sizes.

    Province's guaranteed figure is set in the site quotation.

  • Input length: on the growth-class rows the measured sessions carried 128,000–330,000-token inputs, against about 18,000 for a Kit Think turn.

    The entry-class rows used shorter inputs, so the on-site acceptance test sets the Clinic figure.

  • Streams and answers: Kit Think's team mode runs about 1.5 streams per answer in flight, so 16 guaranteed streams carry about 10 Kit Think answers at once (Hospital about 266, Region about 1,034).

    The 6,000-token Kit Think figure is the live average of all output tokens per answer across every model call (provider token counts: 16.69 million over 2,800 answers in 24 hours), so the busiest-hour clinician figures already include team mode.

  • Clinicians in the busiest hour = guaranteed simultaneous streams × 16. Per clinician-hour: 4 questions × (0.8 × 66 stream-seconds for a 6,000-token Kit Think answer + 0.2 × 7.9 stream-seconds for a 661-token Kit Ask answer) = 217.5 stream-seconds.

    3,600 ÷ 217.5 = 16.55, rounded down to 16.

    The Kit Think length matches the live average of 5,960 tokens over 2,800 answers.

    The Kit Ask length is the measured average over 1,038 answers.

    At 8 questions in the busiest hour, halve the clinician figures.

    At 100% Kit Think, multiply them by 0.82.

  • Named staff: at a planning ratio of one in three named staff active in the busiest hour, multiply the busiest-hour figure by 3.

    Region then serves about 74,000 named staff.

    For scale, BC has 16,438 physicians (CIHI, 2025) and 62,538 regulated nurses (CIHI, 2024).

    BC's clinical lead confirms the ratio.

  • Speed lever: one growth-class server serves 576 users at 100 tokens per second or more, or 256 at 200 or more.

    A small reserved share of each growth-class server runs faster still, for emergency and short Kit Ask traffic.

  • Kit's current hosted service, for reference (measured with test questions, no BC patient data): Kit Ask first words in about 1.5 seconds (median, n = 690, 8–15 November 2026).

    Kit Think Medical's first visible line in about half a second (median, n = 104), with a hard medical question finished in about one to two minutes (emergency 52.1 s, dose 90.7 s, symptom 109.2 s medians).

    Completion times on BC's hardware are set per size in the acceptance schedule.

Upgrade mechanics

  • No new network fabric. Each AI server holds the whole model, so added servers run as independent copies behind the Front Door's load balancer.

    A rebuild uses the same Delivery Bay path as any update.
